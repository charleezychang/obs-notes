- `ng test`
- default testing libraries are Karma (run tests/provide feedback) and Jasmine (unit testing, syntax/structure of tests)
- other testing libraries include: Cypress (comprehensive e2e testing), Jest(unit)-Playwright(e2e)
#### Coverage Report
- coverage report - `ng test --no-watch --code-coverage` generates a report in `/coverage` directory after the tests are complete
- coverage could be configured to be generated every time you test via `angular.json`
- coverage could also be enforced (minimum requirement) via `coverageReporter` key in the configuration but may vary from different testing libraries
#### Testing Services
- `describe('testGroup', fn)` - group related tests together
- `beforeEach(fn)` - use to initialize services before test runs
- `it('testName', fn)` - for actual tests
```ts
// Straight Jasmine testing without Angular's testing support
  describe('ValueService', () => {
    let service: ValueService;
    beforeEach(() => {
      service = new ValueService();
    });
    it('#getValue should return real value', () => {
      expect(service.getValue()).toBe('real value');
    });
    it('#getObservableValue should return value from observable', (done: DoneFn) => {
      service.getObservableValue().subscribe((value) => {
        expect(value).toBe('observable value');
        done();
      });
    });
    it('#getPromiseValue should return value from a promise', (done: DoneFn) => {
      service.getPromiseValue().then((value) => {
        expect(value).toBe('promise value');
        done();
      });
    });
  });
```
